With Blazor Interactive Server, the DI scope is different.

A scoped service can live for the duration of the user's circuit (connection), spanning multiple UI interactions.

That means injecting a scoped DbContext directly into a component can cause problems:
- The context may live much longer than intended.
- Multiple component operations could use the same context concurrently.
- Tracked entities can accumulate over time.
- DbContext is not thread-safe.
